# Implementation sequence and decisions

**Status, 17 October 2026: plan validated; production NO-GO.** First resolve the measured BLS 403 from Cloudflare. The same source works in the workspace. Do not deploy the research snapshot or silently switch to FRED. [Rehearsal evidence and reproduction](rehearsal/README.md) supersedes earlier untested assumptions in this proposal.

The first offering stays **one national urban all-items CPI-U measure, `CUUR0000SA0`, NSA, 1982–84=100, 13 calendar slots**. It supports exact retained-month comparisons and the latest month versus its year-earlier month when both are numeric. It does not support arbitrary lagged annual comparisons, annual averages, state/DC-only requests, CPI-W/chained/core/SA substitutions, monetary interpretation of contract clauses, or unavailable reference months. October 2025 remains unavailable with X; an October 2026 annual comparison must refuse if that base month remains unavailable. No date substitution.

Demand remains the pinned implemented Docusign workflow and BLS MCP maintainer failure reports in [README](README.md), not measured user requests. Scope and arithmetic follow [CONTRACT](CONTRACT.md). Geography is now supported by the documented [CPI/OMB frame derivation](rehearsal/geography-evidence.json); no broader geographic promise is added.

The implementation maintainer owns steps 1–7; the release operator owns steps 8–9 and rollback; the monitoring maintainer owns step 10. These are responsibilities, not invented assignments to named people. Every failed mandatory gate stops activation. Passing a later test cannot waive an earlier semantic failure.

## 5. Cache, version and cite without hiding failures

- **Prerequisite/input:** successful reader; measured cache results and concurrency limitation in the rehearsal. Sources are request-fetched, not embedded snapshots.
- **Components/output:** US entry in `HOLD_SECONDS`/existing cache path; one-hour success TTL and 30-second error TTL with absolute expiry enforced. All selectors reuse the full US source read. A valid cache hit makes zero publisher calls; each cold fill has three original file requests plus at most one verified release-metadata request. Do not claim a global ceiling or cross-request coalescing. No mutable global in-flight request I/O is required by this plan.
- **Version contract:** observation hash includes value, period, dimensions, missingness, footnotes, source and meaningful qualifications; excludes retrieval timestamps. Full response ETag also includes source health. Same ID/version means unchanged; different period means a newly available observation; same ID/new version means changed value/metadata requiring classification against publisher evidence. Missing-to-numeric is a newly available value, not automatically labelled a correction. No server vintage archive is promised; dropped oldest months return explicit unretained-period errors.
- **Verify:** create `test/us-cache.test.js`; exercise conditional GET/HEAD, unchanged refresh, correction, new period, known unavailable month, failed refresh with an old ETag, cached error and recovery. Repeat in isolated Cloudflare preview using the real implemented cache path; include accelerated expiry plus a real configured-TTL revisit. Capture transport counts, bytes, wall time and available runtime CPU metrics; distinguish fixture measurements from real publisher transfers.
- **Pass:** no 304 for failures; no timestamp-only version changes; no misleading max-age beyond remaining expiry; failure and recovery visible; all live files within 8 MiB and source deadline 20 seconds. CPU must remain within the configured Worker limit; record the actual applicable limit rather than assuming the local machine's budget. Concurrent cold misses may duplicate reads and must be reported.
- **Fail response:** reduce/repair within the existing architecture or stop. Persistent rate/resource constraints require a separately justified design; do not introduce a database, scheduler or global coordinator automatically.
