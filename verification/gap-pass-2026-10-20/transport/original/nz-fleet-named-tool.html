Annual Motor Vehicle Fleet Statistics (2024)
This interactive open data tool shows the annual statistics of New Zealand’s historical motor vehicle fleet for the period 2000-2024. The data can be explored and downloaded in machine readable format. A summary of key insights from the data is also provided.

About this tool

This open data tool includes:

  • An interactive dashboard for exploring available data in the Annual Motor Vehicle Fleet Statistics (2024). The dashboard enables the user to choose a data category and drill down to a particular dataset. The specific datasets can be explored and downloaded via an interactive visualisation or downloaded as machine readable .csv.
  • The option to download the complete open data, which includes many other summaries than those presented in the dashboard of the app.

Enquiries
