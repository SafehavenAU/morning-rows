Git ignores logs by default. Use the emitted exact add-list and force-add only its reviewed evidence paths, then run `/tmp/mr-verify-committed-evidence.py` against the exact resulting commit and emitted audit configuration. Do not call the package complete based only on local file hashes or `git status`. The committed audit must pass again for the pushed exact tree before merge.
